3. **Prompt visibility.** In `KitchenController` (or a small block in OrderController if it already owns prompts; grep `ProximityPrompt` first) connect `workspace.Customers.ChildAdded` and existing children. For each NPC `ServePrompt`: each 0.2 s compute `fraction = (PatienceEnd - GetServerTimeNow()) / PatienceTotal` from the model attributes; set `prompt.Enabled = true` and `ActionText = "Serve"` when `model:GetAttribute("AssignedUserId") == LocalPlayer.UserId`; `Enabled = true` and `ActionText = "Rescue"` when `fraction < 0.3` and the player is clocked in; otherwise `Enabled = false` (design §4.6). Disconnect everything on cleanup. This is local view only; the server already enforces.
4. **OrderTicket bars.** When `CurrentOrder.PatienceEnd` exists, render a patience bar under the label on the ticket, copying the bubble bar in `src/server/Modules/CustomerService/Npc.luau` `buildBubble` and the progress-bar pattern STYLE.md §3.6 / §6.6 names: green above 50%, `GOLD_MID` at or below 50%, `RED` at or below 25% (`CustomerConfig.PATIENCE_YELLOW_FRACTION`, `PATIENCE_RED_FRACTION`). Fill width updates each frame (Heartbeat, disconnected on cleanup). The ticket label is `CurrentOrder.Label`. Clearing (`CurrentOrder == nil`) hides the bar. Use only tokens in STYLE.md; if the ticket has no progress-bar pattern to copy, STOP-AND-ASK.
5. Run `stylua` then `gate` on all changed files.
